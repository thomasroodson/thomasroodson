# Hi, I'm Thomas Roodson

I'm a front-end developer from Brazil with 10+ years of experience building and maintaining websites and web applications.

Most of my work is about turning designs and requirements into interfaces that work well in the browser — from day-to-day improvements on existing sites to building new pages and applications. I work mainly with JavaScript and TypeScript, and use React, Next.js, Vue, and SvelteKit depending on the project. I also work with WordPress when a project calls for it.

Outside the code, I care about keeping projects understandable, making content easy to manage, and leaving things in a state that another developer can work with.
